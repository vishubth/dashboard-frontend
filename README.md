An enterprise-style intelligence platform frontend that transforms AI-extracted document intelligence into interactive dashboards, relationship views, profile summaries, and investigative workflows.

## Executive Summary

The AI Profile Intelligence Portal serves as the presentation and workflow layer for a document intelligence platform. The system ingests structured profile data generated from AI-powered document analysis pipelines and converts it into actionable visual intelligence.

The application provides role-based user experiences, protected workflows, administrative controls, and interactive analytics designed for investigative, compliance, operations, and due-diligence use cases.

## System Architecture

```text
Frontend (React + Vite)
          ↓
REST APIs
          ↓
FastAPI Backend Services
          ↓
AI Document Processing Pipeline
          ↓
Structured Intelligence Profiles
```

## End-to-End Workflow

1. Users submit profile intelligence requests.
2. Documents are processed through AI extraction pipelines.
3. Structured intelligence profiles are generated.
4. Backend APIs expose normalized profile data.
5. The portal transforms extracted intelligence into interactive visual experiences.
6. Users and administrators review, analyze, and manage intelligence workflows.
